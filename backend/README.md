# DPRate back end

PHP 8 JSON API with PDO and MySQL. Setup, endpoints, security notes and hosting steps are in the
[main README](../README.md).

Quick start (Windows + XAMPP), from the project folder:

```
C:\xampp\php\php.exe -S 127.0.0.1:8000 -t backend/public
C:\xampp\php\php.exe backend/tests/api_test.php
```
